### [Better Downed Indicators](https://www.nexusmods.com/warhammer40kdarktide/mods/635)
<img width="479" height="512" alt="image" src="https://github.com/user-attachments/assets/6f3bece4-a4c1-4adc-bef4-5fc87fac4d29" />

Replaces generic downed icons with specific status icons (pounced by hound, netted by trapper, grabbed by mutant) and adds aggro borders.

Thanks to [GideonAriphael](https://www.nexusmods.com/warhammer40kdarktide/users/1992757) for his mod [Ring HUD](https://www.nexusmods.com/warhammer40kdarktide/mods/520) for the ideas and hooks! :)

<details>
<summary><b>Mod Settings / Commands</b></summary>

**Panel Indicators**
- Icon Style [Glowing, Plain (Uses Status Colors), Plain (Teammate Color)]
- Enable Background Tint
- Enable Personal Panel Indicator (Offset X/Y)
- Enable Team Panel Indicators (Offset X/Y)

**World Markers**
- Enable Floating Markers
- Icon Style [Glowing, Plain (Uses Status Colors), Plain (Teammate Color)]
- Icon Size

**Status Colors**
- Requires 'Plain' Style to Recolor (Knocked-down, Hanging, Pounced, Netted, Consumed, Grabbed, Mutant-charged, Hogtied, Dead, Respawning)
- Always Recolorable (Warp-grabbed, Auspex, Luggable, Healing, Helping, Interacting)

**Aggro Detection**
- Enable Aggro Glow on Personal Panel
- Enable Aggro Glow on Team Panels
- Aggro Glow Threats & Colors (Pox Burster, Disabler, Sniper, Captain/Twins, Monstrosity, Daemonhost, Grenadier/Tox Bomber, Crusher/Mauler, Flamer, Rager)
</details>
